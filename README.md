# 🎮 PixelQuest – 2D Pixel Platformer Engine & Level Builder

> A lightweight, framerate-independent 2D platformer game engine and drag-and-drop tilemap editor built with vanilla HTML5 Canvas and JavaScript.

## 🔗 Quick Links
- **Live Demo:** https://pixelquest-psi.vercel.app/
- **Tech Stack:** HTML5 Canvas, CSS3, JavaScript (ES6+), Web Audio API

---

## ✨ Core Features
- **Custom Physics Engine:** Axis-Aligned Bounding Box (AABB) collision detection, velocity capping, and gravity acceleration.
- **Delta Time Synchronization:** Ensures consistent 60 FPS movement logic across high refresh rate displays.
- **Interactive Level Editor:** Real-time tile painting with grid overlays and hotkeys.
- **Level State Serialization:** Import and export custom level layouts via JSON files.
- **8-Bit Web Audio Synthesizer:** Procedural audio generated on-the-fly using the browser's Web Audio API.
